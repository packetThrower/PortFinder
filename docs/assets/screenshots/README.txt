# Screenshots

Drop real screenshots in here, replacing the placeholder solid-color
PNGs. Filenames must match what the docs reference:

| File | Where it's used |
|---|---|
| `macos.png` | docs index — macOS card |
| `windows.png` | docs index — Windows card |
| `linux.png` | docs index — Linux card |
| `cli.png` | docs index — CLI card |
| `macos-result.png` | usage/gui.md — captured-result hero shot |

Recommended: 600×420 or larger, PNG. The Material theme renders them at
the column width of the cards on the index, so anything between 400 and
1200px wide looks fine.
